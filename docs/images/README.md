# Screenshot slot

One real, user-provided screenshot is reserved at `docs/images/screenshot.png`.
No screenshot has been supplied for this repository yet. Do not substitute a generated image.

When the screenshot arrives:

1. Check it for visible conversations, private paths, account information, and credentials before publishing.
2. Save the approved image as `screenshot.png`.
3. Enable the existing Markdown image line in both root READMEs and remove the placeholder sentence.
4. Rebuild the release assets. The build script automatically includes this one image when present.
